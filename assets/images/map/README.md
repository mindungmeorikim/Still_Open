2.5D map image slots
====================

Put final map images in this folder using these filenames:

- store_map_base.webp
- store_map_locked_overlay.webp
- zone_basic_unlocked.webp
- zone_extra_shelf_locked.webp
- zone_extra_shelf_unlocked.webp
- zone_cold_food_locked.webp
- zone_cold_food_unlocked.webp
- zone_premium_store_locked.webp
- zone_premium_store_unlocked.webp

Recommended base map ratio: 16:9.

The game will still show a CSS placeholder map when these images are missing.
